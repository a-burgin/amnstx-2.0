# AMNS TX Website Version 2

Multi-page Next.js website for AMNS TX / A Mobile Notary Service.

## Upload to GitHub
Unzip this folder and upload the inside files/folders to your GitHub repository root:
- package.json
- next.config.mjs
- app folder
- README.md
- .gitignore

Do not upload the zip itself as the website.

## Vercel Settings
- Framework Preset: Next.js
- Install Command: npm install
- Build Command: npm run build
- Output Directory: leave blank
