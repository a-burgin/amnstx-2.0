# AMNS TX Website

Vercel-ready package.

## Deploy
1. Upload these files to the root of the GitHub repo.
2. In Vercel, import the repo normally.
3. Vercel should auto-detect Vite.
4. No manual build settings should be required.

Default Vercel build:
- Install: `npm install`
- Build: `npm run build`
- Output: `dist`
