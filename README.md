# AMNS TX Merged Website Package

Deploy-ready static website package for AMNS TX.

## Included
- Home, About, Services, Mobile Notary, Online Notary
- Tools page with ID checker and quote estimator
- Business Services, Pricing, FAQ, Contact, Booking
- Floating Call / Text / Online action buttons
- Separate call number and text number
- Mobile responsive black/gray/white premium design

## Deploy
Upload this full folder to GitHub or Vercel. The main page is `index.html`.
