# AMNS TX Website Packet

Upload this folder to GitHub/Vercel.

Important: Do not upload node_modules. Vercel installs dependencies automatically from package.json.

Files included:
- package.json
- index.html
- vercel.json
- src/main.jsx
- src/styles.css

Deploy steps:
1. Upload these files/folders to GitHub.
2. Import the GitHub repo into Vercel.
3. Vercel will run npm install automatically.
4. Deploy.
